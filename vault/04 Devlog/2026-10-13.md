# 2026-10-13

## Original APK balance reference

Added [[Original Game - APK Balance Audit]] to the reference notes. It records 249 native weapon definitions cross-checked between ARM and x86, character/enemy/gadget data, economy and unlock logic, source evidence, and remaining uncertainties. Updated [[Original Game]] and [[Original Game - Items and Economy]] to reflect that base weapon numbers are now recovered. JSON data remains outside the repository at the path recorded in the audit. No Roblox Studio or game-design changes were made.

## GDD first draft

Fixed inconsistencies in the original-game notes. Drafted the [[Game Design Document]] with the developer's decisions:
- a new IP inspired by the original, not a remake,
- a 2.5D side-scroller (ADR [[0003-2.5d-side-scroller]]),
- 1–4 player co-op,
- runs of trains with a hub,
- over-the-top comedy,
- four themes (Ninjas, Undead, Robots, Wild West),
- an original-style economy.

Everything else in the GDD is marked **[proposed]**. Title brainstorm is in [[Title Ideas]]. No Studio changes.
